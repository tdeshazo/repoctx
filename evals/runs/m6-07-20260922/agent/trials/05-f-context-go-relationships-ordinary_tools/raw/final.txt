Unit and unresolved targets are skipped by:

```go
if n >= len(r.Symbols) || !wanted[k] || sources[r.Symbols[n].File] == nil {
    continue
}
```

The first condition excludes external graph nodes: package/file units, modules, and unresolved symbols. The source check excludes denied, unavailable, or otherwise unserved repository symbols. This prevents unit hubs and globally merged unresolved names such as `print` from connecting unrelated code. Graph construction is in [`pkg/compiler/compiler.go:617`](/tmp/repoctx-m6-07-20260922/trials/05-f-context-go-relationships-ordinary_tools/workspace/repository/pkg/compiler/compiler.go:617).

4. Byte-bounded response construction: [`pkg/agentctx/build.go:138`](/tmp/repoctx-m6-07-20260922/trials/05-f-context-go-relationships-ordinary_tools/workspace/repository/pkg/agentctx/build.go:138)
   - Reserves one quarter of `MaxBytes`, capped at 4096, for imports and graph evidence.
   - Adds symbols/units greedily, shrinking definitions to excerpts when necessary.
   - Adds imports as supporting evidence, then adjacent relationships via [`relationships`](/tmp/repoctx-m6-07-20260922/trials/05-f-context-go-relationships-ordinary_tools/workspace/repository/pkg/agentctx/relationships.go:19).
   - Every trial is rendered and measured. JSON includes the final newline; Markdown includes its complete fenced representation.
   - [`Render`](/tmp/repoctx-m6-07-20260922/trials/05-f-context-go-relationships-ordinary_tools/workspace/repository/pkg/agentctx/render.go:9) measures actual serialized bytes, not source bytes or gzip size. Final overflow returns an error; JSON is never truncated.

Relationship output is adjacent evidence only, capped by `MaxRelations`; it may show edge kinds not used for traversal. Calls targeting repository symbols are marked `name_heuristic`; unresolved calls are `unresolved`. Call links use same-language, same-unit name heuristics, without type checking, dispatch resolution, complete alias/module resolution, or runtime semantics. Therefore they cannot prove the runtime callee, causality, behavior, or absence of an unlisted call.
