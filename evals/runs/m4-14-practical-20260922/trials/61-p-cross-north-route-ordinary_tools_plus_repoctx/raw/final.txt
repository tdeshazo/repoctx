The documented policy says north-region parcels pass through depot N1 before delivery ([docs/routing.md:3](repository/docs/routing.md#L3)). Code represents that route as the lane value `"north-n1"` when `region == "north"` ([parcel/routing.py:9](repository/parcel/routing.py#L9)). `prepare_parcel` passes the region to `choose_lane` and includes the chosen lane in its result ([parcel/service.py:5](repository/parcel/service.py#L5)).

The code has two qualifications: hazardous parcels use `"ground"` first, and a caller that supplies `requested` directly to `choose_lane` gets that lane before the north-region default is considered ([parcel/routing.py:4](repository/parcel/routing.py#L4)). There is no separate depot stop modeled in the listed code; N1 is encoded in the lane name.
