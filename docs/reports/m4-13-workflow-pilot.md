# M4-13: exploratory agent workflow pilot

On 2026-09-22, four paired synthetic tasks passed with ordinary tools and with
ordinary tools plus repoctx. This pilot demonstrated feasibility, **not an
efficiency gain**. Improve the workflow primer, then validate on realistic tasks
before further retrieval tuning or the larger confirmatory M4 study.

## Method and evidence

The [frozen corpus](../../evals/pilot/README.md) covers documentation lookup,
localization, cross-file explanation, and a batch-limit change. Inputs and answer
keys were frozen before trials. Conditions alternated order in fresh workspaces,
using gpt-5.6-luna at medium reasoning, Codex CLI 0.155.1, a 300-second timeout,
and an advisory 16-call limit. All completed within the limits. The model alias
could not be resolved to an immutable revision.

Both conditions received the same filesystem grants; probes verified workspace
write, evaluator/sibling read denial, and socket denial. A pinned binary was
present in both workspaces, but only treatment exposed it in PATH and instructions;
baseline explicitly prohibited repoctx and no baseline trace invoked it. Treatment
used discovery in all four trials. No compilation was invoked, so compilation
cost was zero; operator build/install cost was unmeasured and excluded.

Two reviewers checked answers against the withheld keys. Both changes modified
only `MAX_BATCH_SIZE = 8` to `12`; independent checks ran on fresh source copies
with isolated Python and a timeout. Generated bytecode was excluded from these
copies. Raw trial evidence, candidate sources, exact measured runner, protocol,
usage, and independent checks are in the [run archive](../../evals/runs/m4-13-20260922/valid/protocol.json).
[Scored results](../../evals/runs/m4-13-20260922/valid/scored-results.json) retain per-task accounting;
[checksums](../../evals/runs/m4-13-20260922/SHA256SUMS) cover the archive.

## Friction and decision

Three treatment trials guessed unsupported `read -path` and recovered with
`-file`. Two reads and one repeated discovery revisited already decisive evidence.
The current primer now shows exact read syntax and says to stop when discovery
answers the task. This revision occurred **after** measurement; its benefit has
not been measured. No CLI alias or retrieval-engine change follows from this run.
Both change trials also tried `git diff` in non-Git fixture exports and recovered.

One earlier attempt was aborted after a shared binary path proved inaccessible:
two trials completed and a third was interrupted. Its [traces](../../evals/runs/m4-13-20260922/aborted/protocol.json)
remain separate from paired results. Completed aborted trials consumed 42.35 seconds,
126,841 input and 838 output tokens; interrupted usage is unavailable. Two successful
readiness calls used 30,381 input and 10 output tokens. Setup, aborted work, operator
review, and independent evaluation are excluded from the table, not free work.

Four single pairs on one tiny synthetic repository cannot establish general task
success or savings. The next M6-07 step is realistic first-use validation of the
simplified guidance, including incomplete evidence and useful indexed expansion.
The held-out M4 protocol and improvement gates remain unchanged.
